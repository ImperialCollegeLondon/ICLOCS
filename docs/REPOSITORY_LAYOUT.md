# Repository Layout

This repository contains the MATLAB source, templates, examples, and project-maintenance files for ICLOCS.

## Top-Level Folders

- `src`: core ICLOCS MATLAB source code.
- `usr`: user templates for single-phase, multi-phase, and NMPC workflows.
- `exampleProblems`: implemented ICLOCS examples using the main solver workflows.
- `exampleProblems_fmincon`: examples configured for `fmincon` workflows.
- `closedLoopExamples`: script-based and Simulink-based closed-loop/NMPC examples.
- `tests`: MATLAB unit and smoke tests.
- `tools`: repository maintenance and setup helpers.
- `docs`: repository documentation, generated indexes, and usage metrics.
- `.github`: GitHub Actions workflows, issue templates, and pull request template.

## Path Guidance

Add the `src` tree to MATLAB's path for ICLOCS itself. Add only one example folder at a time when running examples because several examples intentionally reuse function names.

```matlab
addpath('tools')
setupIclocsPath
addpath(fullfile(pwd,'exampleProblems','DoubleIntegratorTracking'))
```

## Generated Files

- `docs/API-INDEX.md` is generated by `python3 tools/generate_api_index.py`.
- `docs/metrics/*.json` files are updated by the `Update usage metrics` GitHub Actions workflow.
