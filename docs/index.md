# ICLOCS Documentation

ICLOCS is the Imperial College London Optimal Control Software for MATLAB. It supports direct optimal-control problem transcription and solution workflows with supported nonlinear programming solvers.

## Quick Install

From the repository root in MATLAB:

```matlab
installIclocs
```

From a terminal with MATLAB R2019a or later:

```bash
matlab -batch "installIclocs"
```
