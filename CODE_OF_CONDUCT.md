# Code Of Conduct

ICLOCS is an academic open-source project. We want the repository to be useful to researchers, students, and practitioners with different levels of optimal-control and MATLAB experience.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent while asking for enough detail to reproduce technical issues.
- Keep discussions focused on the software, documentation, examples, and research use cases.
- Credit prior work and respect licensing.

## Unacceptable Behavior

- Harassment, personal attacks, or discriminatory language.
- Publishing private information without permission.
- Repeated off-topic or bad-faith disruption.

## Reporting

Report conduct concerns to the repository maintainers or, when appropriate, use the contact address listed in the README and project website.

Maintainers may edit, hide, or remove comments and may restrict participation when needed to keep the project constructive.
